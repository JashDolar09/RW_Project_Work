## Features

- Menu Driven Program
- Input Data (Manual or Sample Data)
- Display Dataset Summary
- Calculate Average
- Find Duplicate Values
- Display Unique Values
- Demonstrate *args
- Demonstrate **kwargs
- Calculate Factorial using Recursion
- Filter Data using Lambda Function
- Use Global Variable
- Return Multiple Values
- Sort Data (Ascending & Descending)
- Display 2D List
- Display Function Descriptions using __doc__

## Assumptions

- User enters only numeric values.
- Dataset is a one-dimensional list of integers.
- Sample data can be used if manual input is not required.
- Factorial is calculated for positive integers.
- Lambda function filters values greater than or equal to the entered threshold.
- Sorting is performed in ascending or descending order.
- The 2D list uses predefined sample data.
- Function descriptions are displayed using the `__doc__` attribute.
